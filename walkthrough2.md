# ReFruit - Upcycled Fruit Energy Bars Landing Page

I have successfully created the landing page for **ReFruit**, focusing on sustainability and the "upcycled" product theme.

## 🎨 Design Highlights

### Theme: "Nature's Second Chance"
- **Colors**: Vibrant Orange (`#FF6B35`) for energy, Deep Green (`#004E35`) for nature, and Cream (`#FEFCF5`) for a natural, organic feel.
- **Typography**: `Outfit` font for a modern, clean, and friendly aesthetic.

### Components

#### 1. Header
- Sticky navigation bar with the "ReFruit" brand.
- Clear links to "Benefits" and "Our Mission".
- "Shop Now" call-to-action button.

#### 2. Hero Section
- **Headline**: "Powered by Nature, Rescued for You."
- **Focus**: Promoting the circular economy concept.
- **Visuals**: Placeholder for a high-quality product shot, styled with a subtle pattern.

#### 3. Features Grid
- Grid layout highlighting 3 key selling points:
  - ♻️ **Circular Economy** (Fighting waste)
  - 🌱 **100% Natural** (Clean ingredients)
  - ⚡ **Sustained Energy** (Functional benefit)

#### 4. Footer
- Comprehensive footer with links and social placeholders.
- Consistent dark green branding.

## 🛠️ Tech Stack
- **Framework**: Angular 19 (Standalone Components)
- **Styling**: Vanilla CSS (Variables, Flexbox, Grid)
- **Build System**: Angular CLI

## Turnaround
The project was initialized with the Angular CLI, configured with a component-based architecture, and styled according to the plan. The build has been verified successfully.
